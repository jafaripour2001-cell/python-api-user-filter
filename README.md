Python API User Filter

A Python project that fetches user data from a REST API and filters users based on their city.

Features

- Fetches user data from an API
- Handles HTTP request errors
- Parses JSON responses
- Filters users by city
- Uses a simple and clean Python structure

Technologies

- Python
- Requests
- REST API
- JSON

Installation

Clone the repository and install the required dependency:

pip install -r requirements.txt

Usage

Run the Python script:

python main.py

The program retrieves user data from the API and allows users to be filtered based on their city.
